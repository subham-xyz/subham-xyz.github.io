KittySuite original glyph index, generated from 1,382 individually verified SIL Open Font License families. Fonts are subset to Latin characters and instantiated at their regular default axes. Modified font internal names are renamed KittySuite Index to respect reserved font names. Original family names in the index identify the source family, not a new font release. Each corresponding *-OFL.txt contains the original copyright and licence. Source links and SHA-256 hashes are in manifest.json. No proprietary matching database was used. Index and build code are authored for KittySuite.
